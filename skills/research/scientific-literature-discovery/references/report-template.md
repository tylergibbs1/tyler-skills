# Discovery report template

Use this for 1–3 finalists. Write every scientific factual claim with a verifiable source identifier.

## 1. Scope and audit trail

- Research question and participating fields:
- UTC date; databases; search strings and cutoff:
- Papers found / screened / full text read (differentiate these):
- Inclusion/exclusion, missing full text, language and indexing gaps:

## 2. Evidence ledger

| Claim ID | Work title / DOI or PMID / URL | Context, design, measured result | Caveats | Full / abstract / metadata |
|---|---|---|---|---|

## 3. Candidate H01 — [specific mechanism]

- **Status:** proposed / literature-supported / computationally tested / independently replicated / refuted
- **Directional claim:** Under [condition], [mechanism] predicts [outcome] versus [baseline].
- **Bridge:** A→B: [source IDs]; B→C: [independent source IDs]; A→C: [hypothesis or direct evidence].
- **Why cross-paper connection matters:** [vocabulary, hidden moderator, method transfer].
- **Prior-art verdict:** already studied / partial extension / not found in scoped search / unresolved; exact queries and date; closest prior study.
- **Best supporting evidence:** [what the publications actually tested].
- **Against it:** [null/contradictory source, confounder, alternative mechanism].
- **Falsifying prediction:** [measurement and result that would disprove claim].
- **Next experiment:** [public data, controls, primary outcome, holdout/replication, code plan].
- **Execution:** not run OR exact code, versioned dataset and measured output.
- **Important uncertainties:** [limitations and context differences].
